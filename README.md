# Модель межотраслевого баланса Леонтьева

Модель "Затраты-Выпуск" с параллельным C++ решателем.

## Основные возможности

- Дашборд с ключевыми метриками
- Тепловые карты матриц A и L
- Анализ мультипликаторов выпуска и затрат
- Сценарный анализ экономических шоков
- Сетевой анализ связей между отраслями
- Параллельный C++ решатель СЛАУ (метод сопряжённых градиентов)
- Многовариантные расчеты для множества правых частей

## Источники данных

- Eurostat (64 отрасли, 2010-2022, 27 стран)
- EXIOBASE (200+ отраслей, 2015-2022, 11 стран)

## Архитектура

- app.py - Streamlit интерфейс
- remote_solver.py - Flask сервер
- cpp_solver/cg_solver.cpp - C++ решатель с OpenMP
- cpp_bridge.py - мост между Python и C++
