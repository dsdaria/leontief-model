# Модель межотраслевого баланса Леонтьева (Leontief Input-Output Model)

Реализация классической экономико-математической модели линейного программирования «Затраты–Выпуск» (Input-Output Model) Василия Леонтьева. Проект сочетает в себе строгий макроэкономический анализ и современные вычислительные технологии (Parallel C++, Streamlit, Docker).

Ссылка на репозиторий: [://github.com](https://://github.com/tree/main)

---

## 📈 Экономическая сущность и назначение модели

Модель описывает структурные взаимосвязи между различными отраслями национальной или региональной экономики. Она позволяет определить, сколько продукции должна произвести каждая отрасль, чтобы удовлетворить как внутренние производственные нужды, так и конечный потребительский спрос.

### Основное уравнение модели:
$$X = AX + Y$$

Где:
* **$X$ (Вектор валового выпуска):** Совокупный объем производства каждой отрасли.
* **$Y$ (Вектор конечного спроса):** Продукция, идущая на потребление домохозяйствами, госзакупки, инвестиции и чистый экспорт.
* **$A$ (Матрица коэффициентов прямых затрат):** Технологические параметры экономики, где элемент $a_{ij}$ показывает, сколько единиц продукции отрасли $i$ необходимо затратить для производства одной единицы продукции отрасли $j$.

### Решение модели через Матрицу Леонтьева:
Для прогнозирования валового выпуска $X$ при изменении целевого спроса $Y$ используется обратная матрица Леонтьева (матрица полных затрат):
$$X = (I - A)^{-1} Y$$

Где **$(I - A)^{-1}$** — матрица полных затрат, отражающая как прямые, так и косвенные затраты во всей цепочке поставок (эффект мультипликатора).

## 🛠 Реализованный экономический функционал

Программа автоматизирует ключевые этапы макроэкономического анализа:

1. **Проверка продуктивности матрицы $A$:** Оценка жизнеспособности экономической системы (матрица продуктивна, если все элементы $(I - A)^{-1}$ неотрицательны, а спектральный радиус матрицы $A$ меньше 1).
2. **Расчет матрицы полных затрат (МПЗ):** Определение совокупной потребности в ресурсах с учетом синергетических эффектов между секторами.
3. **Сценарное макромоделирование (What-If анализ):** Оценка влияния изменения конечного спроса $Y$ (например, рост госзакупок, санкционные ограничения, изменение импорта) на объемы производства $X$ всех связанных отраслей.
4. **Анализ структурных сдвигов:** Визуализация межотраслевых потоков ($AX$) для выявления критически зависимых секторов экономики.

## 🏗 Архитектура проекта и вычислительное ядро

Экономические системы включают сотни отраслей, что делает расчет матрицы $(I - A)^{-1}$ ресурсоемким. Для этого в проекте разделены интерфейсная и расчетная части:

```text
├── app.py                   # Web-интерфейс (Streamlit): визуализация матриц, графиков и сценариев
├── remote_solver.py         # Вычислительный сервер для обработки матричных уравнений
├── data_loader.py           # Модуль импорта экономических данных (матриц БМБ)
├── leontief_model.py        # Экономическая логика моделирования
├── cpp_bridge.py            # Интеграционный мост Python -> C++
└── cpp_solver/              # Высокопроизводительное ядро (C++ + OpenMP) для быстрых СЛАУ
```

* **C++ решатель (Метод сопряженных градиентов):** Использует параллельные вычисления для моментального расчета крупных межотраслевых балансов без потери точности округления, свойственной стандартным библиотекам Python на больших данных.

## 🚀 Быстрый запуск

### 1. Локальное окружение (Python + C++)
```bash
# Клонирование репозитория
git clone https://://github.com.git
cd leontief-model

# Установка зависимостей
pip install -r requirements.txt

# Компиляция параллельного C++ ядра (Linux/OpenMP)
cd cpp_solver && g++ -O3 -shared -fPIC -fopenmp -o cg_solver.so cg_solver.cpp && cd ..

# Запуск интерактивного дашборда
streamlit run app.py
```

### 2. Развертывание в Docker (Рекомендуется)
Полностью изолированная сборка со всеми скомпилированными математическими библиотеками:
```bash
docker-compose up --build
```
После запуска интерфейс доступен в браузере по адресу `http://localhost:8501`.

## 📊 Пример интерпретации результатов в интерфейсе

1. **Тепловая карта матрицы $A$:** Позволяет визуально определить наиболее ресурсоемкие отрасли (например, металлургия или энергетика), которые потребляют больше всего промежуточной продукции.
2. **График изменения выпусков:** Наглядно показывает, как 10%-й рост спроса в секторе «Строительство» каскадом вызывает рост в секторах «Производство стройматериалов» (прямой эффект) и «Грузовые перевозки / Энергетика» (косвенный эффект).
